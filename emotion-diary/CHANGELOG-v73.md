# 감정일기 v73 변경 사항

v72 최종 점검의 P0(키보드로 기록 불가)과 문구 3가지를 고친 버전이에요. `python3 tools/build_v73.py <출력.html> 감정일기_v72.html`로 다시 만들 수 있어요.

## 키보드로 기록하기 (P0)
- 감정 나침반에 Tab으로 갈 수 있어요(`tabIndex=0`, `role="button"`). Enter나 Space를 누르면 감정 목록 시트가 열려요.
- 감정 시트를 대화상자(`role="dialog"`, `aria-modal`)로 표시해요.
  - 열리면 첫 버튼으로 포커스가 가요.
  - Tab은 시트 안에서만 돌아요.
  - Esc를 누르면 닫히고 포커스가 감정 나침반으로 돌아가요.
- 3단계로 넘어가면 본문 입력칸으로 바로 포커스가 가요.
- 검증: 키보드만으로 홈 → 기록하기 → 감정 선택 → 세부 감정 → 문장 입력 → 저장을 마쳤어요. 마우스·터치 흐름도 그대로예요.

## 문구
- "감정 로그"를 "감정일기"로 통일했어요(5곳).
- "~합니다"체 9문장을 해요체로 바꿨어요(이용 안내, 개인정보, 알림·앱 설정 안내 등).
- "비어있어요"를 "비어 있어요"로 고쳤어요.

## 검증
- 대비·글자 크기 위반 0건, 이름 없는 컨트롤 0건이에요.
- 버튼 49개를 다시 눌러 봤는데 오류 0건이에요.
- v72 대비 화면 차이는 문구가 바뀐 화면에서만 생겼어요(최대 1.5%).

## 이후 정리 (서비스명 · 용어)
- 서비스명을 **감정로그**로 통일했어요. 화면 문구(이용 원칙, 스크린리더 이름, 제목)와 파일명을 바꿨어요: `감정로그_v73.html`, `usability-test-kit/감정로그_*`, `docs/감정로그_사용성테스트_가이드_v73.pdf`.
- 감정 입력 기능의 이름을 **감정 나침반**으로 통일했어요(스크린리더 이름과 테스트 가이드의 "마음 지도").
- `tools/build_v73.py`로 v72에서 다시 만들면 지금 파일과 똑같이 나와요. v71 · v72 파일과 변경 기록은 당시 이름 그대로 뒀어요.
