# 감정일기 v72 변경 사항

v71 점검 리포트의 1·3·4·5단계를 반영한 버전입니다. 2단계(샘플 데이터 분리)는 모든 사용자에게 "예시"라고 안내할 계획이라 이번에는 바꾸지 않았어요.

`python3 tools/build_v72.py <출력.html> 감정일기_v71.html`로 v71에서 그대로 다시 만들 수 있어요.

## 1단계 · 접근성
- 뷰포트의 `maximum-scale=1`을 지워 두 손가락 확대를 허용했어요.
- 알림 토글 3개에 이름을 붙였어요("감정 기록 알림" 등). 켜짐 상태(`aria-pressed`)는 원래 있었어요.
- 기록 3단계 본문 입력칸과 "그날에 덧붙일 말" 입력칸에 라벨을 붙였어요.
- 하단 탭바에 현재 탭 표시(`aria-current="page"`)를 넣었어요.
- 달력 칸 이름을 "2026-10-04 감정 기록"에서 "10월 4일 불안 기록"으로 바꿨어요.
- 닉네임 입력칸은 이미 `<label>`로 감싸져 있어서 그대로 뒀어요. v71 점검 리포트의 "라벨 없음"은 점검 스크립트의 오탐이었어요.

## 3단계 · 터치 영역 44px
- 토큰 `--size-touch-min: 44px`를 추가했어요.
- **보이는 크기를 44px로 키운 요소:** 달력 날짜 칸(36×32 → 44×44), 일간/주간/월간 탭, 작품 갤러리/캐릭터 도감 탭, 세부 감정 칩, 날짜 칩, 기록 플로우의 뒤로·닫기, 이전 달 버튼.
- **모양은 두고 누르는 영역만 넓힌 요소:** 건너뛰기, 알림 토글. 가운데에서 상하좌우 22px 지점까지 눌리는 걸 확인했어요.
- 달력 칸과 탭은 크기를 정하던 원본 규칙의 값을 토큰으로 바꿨어요. 나머지는 `<style id="touch-targets">` 한 곳에 모아 뒀어요.

## 4단계 · 간격 · 그림자 토큰
- 토큰 `--spacing-4xl: 40px`와 `--spacing-5xl: 48px`를 추가했어요.
- padding·margin·gap 1,970곳을 가장 가까운 spacing 토큰으로 바꿨어요(최대 ±4px). 2px 미만, 48px 초과, 음수, `calc()`는 그대로 뒀어요.
- 단순한 중립색 그림자 73곳을 `--shadow-sm/md/lg`로 바꿨어요. 감정색 글로우와 인셋 그림자는 그대로 뒀어요.

## 5단계 · Button 컴포넌트
- `src/components/Button/`에 `Button.tsx`, `Button.css`, `index.ts`를 만들었어요. props(`variant`·`size`·`disabled`·`label`)가 Figma `Components/Button` 프로퍼티와 1:1로 맞아요.
- 프로토타입에 흩어져 있던 주요 버튼 클래스 34곳과 이전/다음 분할 버튼에 `ds-button ds-button--primary|secondary ds-button--lg`를 달았어요. 사양은 `<style id="component-button">` 한 곳에서 정해요.
- 그 결과 주요 버튼이 48px · 모서리 20px · 15px Bold로 통일됐어요. 이전에는 높이 48/54/56, 모서리 12/16/20이 섞여 있었어요.
- `Button.figma.ts`는 Code Connect 연결 파일이에요. 연결하려면 Figma Organization/Enterprise 플랜과 라이브러리 게시가 필요해요. 지금 L&P 팀은 Professional 플랜이라 MCP 연결이 거부돼서, 파일만 준비해 뒀어요.
- 토큰 `--size-button-lg: 48px`와 `--size-button-md: 40px`를 추가했어요.

## Figma (감정일기 디자인 시스템 v71 파일)
- 변수를 추가했어요: `size/touch-min`, `size/button-lg`, `size/button-md`, `spacing/4xl`, `spacing/5xl`.
- DayCell을 44×44, EmotionChip을 높이 44로 바꾸고 크기 변수에 연결했어요. Button 높이도 변수에 연결했어요.

## 지표 (v71 → v72)

| 항목 | v71 | v72 |
| --- | --- | --- |
| CSS 선언 중 `var()` 비율 | 22.9% | 36.7% |
| padding 토큰 사용 | 1% | 88% |
| margin 토큰 사용 | 0% | 79% |
| gap 토큰 사용 | 0% | 97% |
| box-shadow 토큰 사용 | 9% | 35% |
| 44px 미만 터치 영역 | 128 | 0 (건너뛰기·토글 4개는 누름 영역 확장으로 충족) |
| 이름 없는 컨트롤 | 3 | 0 |
| 대비·12px 위반 / 콘솔 오류 | 0 / 0 | 0 / 0 |
| `!important` | 2,921 | 2,962 (+41, 버튼·터치 영역 레이어) |

## 검증
- Chromium 430×900에서 20개 화면을 v71과 같은 시나리오로 실행했어요. 콘솔 오류는 0건이에요.
- 화면별 픽셀 차이는 1~9%예요. 달력 칸 확대와 간격 정렬, 버튼 통일에서 나온 차이예요.

- Code Connect 연결(플랜 업그레이드 후)
