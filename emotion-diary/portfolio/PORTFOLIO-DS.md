# 포트폴리오 디자인 시스템

감정로그 포트폴리오의 모든 장(1440×810, 16:9)은 **`src/pf-ds.css` 하나를 참조**해요. 글자 크기 · 색 · 모서리 · 그림자는 장 소스에 값으로 쓰지 않고 토큰(`var(--pf-*)`)으로만 써요. 규칙은 `tools/lint.py`가 검사해요.

## 소스 구조와 작업 순서

```
portfolio/
├─ src/
│  ├─ pf-ds.css            토큰 + 공통 요소(초기화 · 캔버스 · 장 머리 · 부제 · 결론 띠)
│  ├─ slides/01~13.html    장별 <title> · <style> · <section class="slide">
│  ├─ assets/              이미지 (asset:<이름>으로 참조)
│  ├─ fonts/pretendard-subset.css   모든 장의 글자를 담은 Pretendard 부분 글꼴
│  ├─ manifest.json        장 순서 · 라벨 · 글꼴
│  ├─ pdf-stills.json      PDF에서 움직이는 이미지 대신 쓸 정지 프레임
│  └─ shell.html           포트폴리오 바깥 틀
└─ tools/
   ├─ build.py             조립 → 감정로그_포트폴리오_<버전>.html (+ --pdf 로 PDF용 장 문서)
   ├─ export_pdf.js        PPT 기본 크기(13.333 × 7.5 in) PDF
   ├─ lint.py              규칙 검사 (토큰 · 데이터 색 · 모서리 · 글꼴)
   ├─ font_subset.py       부분 글꼴 다시 만들기 / 빠진 글자 검사
   ├─ guides.js            기준선 겹쳐 그리기
   └─ legacy/              v83까지 쓰던 빌드 스크립트 (참고용)
```

1. `src/slides/NN.html`을 고쳐요. 값 대신 토큰을 써요.
2. 문구를 고쳤다면 `python3 tools/font_subset.py build <PretendardVariable.ttf>` (원본은 `npm pack pretendard`의 `dist/public/variable/`)
3. `python3 tools/lint.py` → 0 violation
4. `python3 tools/build.py v84 . --pdf` → `node tools/export_pdf.js pdf-pages 감정로그_포트폴리오_v84.pdf`

## PDF
- 페이지 크기는 PPT 기본(와이드 16:9) **13.333 × 7.5 in (960 × 540 pt)**, 한 장 = 한 페이지예요. 1440×810 장을 0.8889배로 인쇄해 여백 없이 맞춰요.
- 글자는 이미지가 아니라 텍스트로 들어가요(복사 · 검색 가능).
- 07 · 09장의 움직이는 이미지는 동작이 보이는 정지 프레임(나침반을 눌러 감정 시트가 열린 장면, 스타일을 바꾼 장면)으로 바뀌어요.
## 글자 단계

| 토큰 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `--pf-fs-label` | 12px | 태그, 축 이름, 출처. **최소 크기** |
| `--pf-fs-caption` | 13px | 보조 설명, 이미지 캡션, 단계 설명 |
| `--pf-fs-body` | 14px | 본문 문단 |
| `--pf-fs-body-strong` | 15px | 강조 본문, 카드 제목 |
| `--pf-fs-lead` | 16px | 부제, 결론 띠 |
| `--pf-fs-h4` / `h3` / `h2` | 18 / 20 / 24px | 카드 · 섹션 제목 |
| `--pf-fs-stat` | 28px | 큰 수치 |
| `--pf-fs-h1` | 32px | 장 제목 |
| `--pf-fs-display` | 40px | 표지, 강조 수치 |

## 규칙
1. 화면에 보이는 크기 기준으로 12px 미만 글자는 없어요. 도식을 축소해 넣지 않아요.
2. 설명 문장은 13px 이상, 본문 문단은 14px 이상이에요.
3. 장 소스에는 px 값 대신 `var(--pf-fs-*)`만 써요.
4. 장 제목만 이어 읽어도 이야기가 이어지게 써요. 한 일보다 이유를 담아요.
5. 결론 띠(INSIGHT)는 주장을 담은 장(03 · 04 · 11 · 12 · 13)에만, 하단 같은 자리에 둬요. 도식 장(05 · 06)과 화면 장(07~10)은 그림이 결론이라 띠 없이 본문을 746px까지 써요.

## 토큰 (src/pf-ds.css)

| 종류 | 토큰 |
| --- | --- |
| 글자 | `--pf-fs-label` 12 · `caption` 13 · `body` 14 · `body-strong` 15 · `lead` 16 · `h4` 18 · `h3` 20 · `h2` 24 · `stat` 28 · `h1` 32 · `display` 40 |
| 중립색 | `--pf-white` `--pf-bg` `--pf-surface-2` `--pf-ink`~`--pf-ink5` `--pf-line` `--pf-line-strong` `--pf-device` |
| 보라 | `--pf-purple-50` ~ `--pf-purple-800` (10단계) |
| 모서리 | `--pf-r-xs` 4 · `sm` 8 · `md` 12 · `lg` 18(카드) · `device` 26(폰) · `pill` 999 |
| 그림자 | `--pf-shadow-card` · `float` · `device` · `device-hl` · `ring` |
| 여백 | `--pf-pad-card` 24 (카드 안쪽) |
| 레이아웃 | `--pf-margin` 88 · `--pf-gutter` 24 · `--pf-col3` 405 · `--pf-content-top` 204 · `--pf-content-end` 686 · `--pf-content-end-nobar` 746 |

**데이터 색 예외:** 앱의 감정 8색과 그 단계, 11장에서 보여 주는 앱 중립색, 04장 경쟁사 표시색은 포트폴리오 색이 아니라 데이터라 값 그대로 써요(`lint.py`의 DATA 목록). 11장의 앱 컴포넌트 예시는 앱의 실제 모서리 값을 보여 주므로 모서리 규칙의 예외예요.

**색 묶음:** 77가지였던 색 중 비슷한 보라 · 회색 32가지를 가장 가까운 토큰으로 합쳤어요(예: `#f6f4fb` · `#f7f6fb` → `--pf-purple-50`). 화면 차이는 장마다 0.5% 이하예요.
