# 포트폴리오 디자인 시스템

감정로그 포트폴리오의 모든 장(1440×810)에 같은 규칙을 적용해요. `tools/pfbuild.py`의 `pf_ds()`가 빌드할 때 모든 장의 글자 크기를 아래 단계로 맞추고, `<style id="pf-ds">`에 토큰을 넣어요.

## 글자 단계

| 토큰 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `--pf-fs-label` | 12px | 태그, 축 이름, 출처. **최소 크기** |
| `--pf-fs-caption` | 13px | 보조 설명, 이미지 캡션, 단계 설명 |
| `--pf-fs-body` | 14px | 본문 문단 |
| `--pf-fs-body-strong` | 15px | 강조 본문, 카드 제목 |
| `--pf-fs-lead` | 16px | 부제, 결론 띠 |
| `--pf-fs-h4` / `h3` / `h2` | 18 / 20 / 24px | 카드 · 섹션 제목 |
| `--pf-fs-stat` | 28px | 큰 수치 |
| `--pf-fs-h1` | 32px | 장 제목 |
| `--pf-fs-display` | 40px | 표지, 강조 수치 |

## 규칙
1. 화면에 보이는 크기 기준으로 12px 미만 글자는 없어요. 도식을 줄여 넣은 장(05 · 06)은 줄이기 전 최소 13px이라, 줄어든 뒤에도 12px 이상이에요.
2. 설명 문장은 13px 이상, 본문 문단은 14px 이상이에요.
3. 단계 사이 값(11.5, 12.5, 13.5, 22px 등)은 바로 위 단계로 올려요.
4. 장 제목만 이어 읽어도 이야기가 이어지게 써요. 한 일보다 이유를 담아요.
5. 결론 띠(INSIGHT)는 주장을 담은 장(03~06, 11~13)에만, 하단 같은 자리에 둬요.

## 색

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--pf-ink` | #18181c | 제목, 본문 |
| `--pf-ink2` | #55535f | 부제, 설명 |
| `--pf-ink3` / `--pf-ink4` | #6a6874 / #74727e | 캡션, 출처 |
| `--pf-point` / `--pf-point-strong` | #6f5fc9 / #5a4ab3 | 제목 강조, 라벨 |
| `--pf-accent` | #8a7bd8 | 도식 선, 보조 강조 |
| `--pf-soft` / `--pf-tint` | #f5f3fa / #efecfa | 패널, 결론 띠 배경 |
| `--pf-bg` / `--pf-line` | #fbfaf8 / #ece9f1 | 장 배경, 구분선 |

감정 8색은 포트폴리오 색이 아니라 앱의 데이터 색이라, 화면과 디자인 시스템 장에서만 써요.

## 측정 (v80 → v81)

| 항목 | v80 | v81 |
| --- | --- | --- |
| 쓰인 글자 크기 종류 | 22가지 | 11단계 |
| 12px 미만 글자가 있는 장 | 11장 (11장은 47%, 최소 9.6px) | 0장 |
| 13px 미만 비율이 30%를 넘는 장 | 03 · 05 · 09 · 11 | 05 · 11 (라벨 · 캡션 위주) |
| 03장 글자 수 / 13장 글자 수 | 637 / 680 | 593 / 498 |
